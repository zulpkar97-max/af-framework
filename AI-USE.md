# AI 使用披露 / AI Use Disclosure

## 状态 / Status

中文：治理文档 / 非 spec

English: governance document / non-spec

## 目的 / Purpose

中文：
本文件说明生成式 AI 工具如何被用于 Ask First (AF) Framework 项目。它用于仓库透明度披露。它不是 canonical AF specification，不是法律意见，也不能替代大学、出版社、资助方、导师或机构政策。

English:
This document explains how generative AI tools are used in the Ask First (AF) Framework project. It is for repository transparency. It is not a canonical AF specification, not a legal opinion, and not a substitute for university, publisher, funder, supervisor, or institutional policy.

## AI 工具如何被使用 / How AI Tools Are Used

中文：
生成式 AI 工具可在本项目中用于：

- 对话式反思 / dialogue-based reflection
- 草稿生成 / drafting
- 结构整理 / structural organization
- 仓库脚手架 / repository scaffolding
- 审查支持 / review support
- AI 辅助仓库与文档执行，包括在使用时的 Codex 或其他类似代码 / 文档代理工具 / AI-assisted repository and documentation execution, including Codex or comparable code/documentation agents when used

这些使用是辅助性的。它们支持思考、组织、编辑、文档工作流和仓库操作，但不把作者身份、原创者地位或最终责任从 Carl (Zulpkar Turxun) 转移出去。

English:
Generative AI tools may be used in this project for:

- dialogue-based reflection / 对话式反思
- drafting / 草稿生成
- structural organization / 结构整理
- repository scaffolding / 仓库脚手架
- review support / 审查支持
- AI-assisted repository and documentation execution, including Codex or comparable code/documentation agents when used / AI 辅助仓库与文档执行，包括在使用时的 Codex 或其他类似代码 / 文档代理工具

These uses are assistive. They support thinking, organization, editing, documentation workflow, and repository operations. They do not transfer authorship, originator status, or final responsibility away from Carl (Zulpkar Turxun).

## 作者身份与责任 / Authorship and Responsibility

中文：
核心理论主张、概念修正、研究方向、采纳或否决决定，以及最终责任，均属于 Carl (Zulpkar Turxun)。

AI 生成文本在经过审查、修订和接受之前，均被视为草稿材料。由 AI 辅助产生的草稿、候选概念、仓库脚手架或审查建议，不会默认成为 canonical AF material。

AI 工具不被列为作者，因为它们不能承担责任、批准最终主张、保证事实完整性，或参与学术问责。

English:
Core theoretical claims, conceptual corrections, research direction, acceptance or rejection decisions, and final responsibility belong to Carl (Zulpkar Turxun).

AI-generated text is treated as draft material unless it is reviewed, revised, and accepted. Draft text, candidate concepts, repository scaffolding, or review suggestions produced with AI assistance do not become canonical AF material by default.

AI tools are not listed as authors because they cannot hold responsibility, approve final claims, guarantee factual integrity, or participate in academic accountability.

## 工具名称与角色分类 / Tool Names and Role-Based Categories

中文：
Codex、ChatGPT、Claude、Gemini 或其他 AI 系统等具体工具名称，可以在日期记录、PR、commit 或 source notes 中作为审计信息保留。但项目级贡献分类应按角色划分，而不是按厂商或产品名称划分。

English:
Tool names such as Codex, ChatGPT, Claude, Gemini, or other AI systems may be recorded in dated entries, PRs, commits, or source notes when relevant for auditability. However, project-level contribution categories are role-based rather than vendor-based.

## 可审计性 / Auditability

中文：
本项目保留 raw notes、candidate concepts、review traces、commits 和 pull requests。这些材料有助于区分 raw material、candidate development、reviewed repository changes 和 canonical specification text。

English:
The project preserves raw notes, candidate concepts, review traces, commits, and pull requests. These materials help distinguish raw material, candidate development, reviewed repository changes, and canonical specification text.

中文：
本文件不是法律意见。它不能替代大学、导师、出版社、资助方或机构政策。若适用外部政策，应直接检查该政策。

English:
This document is not a legal opinion. It is not a substitute for university, supervisor, publisher, funder, or institutional policy. Where an external policy applies, that policy should be checked directly.
