# Event-Center Closure / 事件中心闭合

Status: candidate mechanism / non-canonical
Language status: English working draft; Chinese-first rewrite required before promotion.
Source: 2026-06-06 AF self-application dialogue; raw elements 16-17, 35-40, 48-50
Layer: theory layer candidate; protocol-layer closure condition
Related existing AF sections: cognitive sphere outline; active graph; A/F compression; macro-AF preservation
Summary: A candidate closure condition where A-side compaction and F-side reverse necessity converge on an event center under low-curvature stable deviation.
Proposed rule: An event center may be treated as candidate-closed only when: A-side expression has compacted into a stable candidate A; F-side reverse necessity can trace why the event is required by the parent F; the deviation from the parent AF is low-curvature and stable rather than merely smooth; and any micro-AF closure can be recovered back into the macro-AF before the parent AF is considered closed.
Why this matters: Event-center closure is not dense dialogue summarization. It is a candidate condition for deciding whether a local event has become structurally meaningful to the parent AF without replacing it.
What this is not: This is not proof of sphere theory, not a summary of a dense conversation, not post-hoc narrative closure, and not a claim that every dialogue convergence closes an AF unit.
Open questions: How should A-side compaction be observed? What counts as F-side reverse necessity? How is low-curvature stable deviation distinguished from polished drift? What record is required for micro-AF-to-macro-AF recovery?
Review risks: Reducing closure to summarization; overclaiming theory; treating local event closure as macro-AF closure; ignoring residual deviation from the parent AF.
