## 摘要 / Summary
中文：
事件中心闭合是一个候选闭合条件：A 侧压实与 F 侧反向必要性在事件中心汇合，并且存在低曲率稳定偏差。

English:
Event-center closure is a candidate closure condition where A-side compaction and F-side reverse necessity converge on an event center under low-curvature stable deviation.

## 候选规则 / Proposed Rule
中文：
一个事件中心只有在以下条件同时满足时，才可被视为候选闭合：A 侧表达已压实为稳定候选 A；F 侧反向必要性能够追溯该事件为何被父 F 需要；相对父 AF 的偏差是低曲率且稳定的，而不只是表面顺滑；并且任何 micro-AF 闭合都必须能回收进 macro-AF，父 AF 才能被视为闭合。

English:
An event center may be treated as candidate-closed only when: A-side expression has compacted into a stable candidate A; F-side reverse necessity can trace why the event is required by the parent F; the deviation from the parent AF is low-curvature and stable rather than merely smooth; and any micro-AF closure can be recovered back into the macro-AF before the parent AF is considered closed.

## 为什么重要 / Why This Matters
中文：
事件中心闭合不是密集对话总结。它用于判断一个局部事件是否已经对父 AF 具有结构意义，同时不替换父 AF。

English:
Event-center closure is not dense dialogue summarization. It is a candidate condition for deciding whether a local event has become structurally meaningful to the parent AF without replacing it.

## 这不是什么 / What This Is Not
中文：
这不是球形理论证明，不是密集对话摘要，不是事后叙事闭合，也不是声称每次对话汇合都会闭合一个 AF 单元。

English:
This is not proof of sphere theory, not a summary of a dense conversation, not post-hoc narrative closure, and not a claim that every dialogue convergence closes an AF unit.

## 开放问题 / Open Questions
中文：
如何观察 A 侧压实？什么算 F 侧反向必要性？如何区分低曲率稳定偏差和漂亮漂移？micro-AF 到 macro-AF 的回收需要什么记录？

English:
How should A-side compaction be observed? What counts as F-side reverse necessity? How is low-curvature stable deviation distinguished from polished drift? What record is required for micro-AF-to-macro-AF recovery?

## 审查风险 / Review Risks
中文：
把闭合降维成总结；过度宣称理论；把局部事件闭合误当成 macro-AF 闭合；忽略相对父 AF 的残余偏差。

English:
Reducing closure to summarization; overclaiming theory; treating local event closure as macro-AF closure; ignoring residual deviation from the parent AF.
