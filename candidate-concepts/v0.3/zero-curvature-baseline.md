## 摘要 / Summary
中文：
零曲率基线是用于判断相对 A->F 压实身份偏差的理想基线。它不是事实成功声明，也不表示某个事件或路径已经完成。

English:
Zero-curvature baseline is an ideal baseline for judging deviation from compressed A->F identity. It is not a factual success claim and does not mean that an event or path has already succeeded.

## 候选规则 / Proposed Rule
中文：
零曲率应被视为一种理想协议基线：在该参考状态中，A 侧压实、F 侧必要性和执行路径保持对齐，并且不替换 F。实际工作在被视为稳定进展之前，应检查其相对该基线的曲率偏差或残余。

English:
Zero-curvature should be treated as an ideal protocol baseline: a reference state in which A-side compaction, F-side necessity, and execution path remain aligned without substituting F. Actual work should be reviewed for curvature deviation or residual from that baseline before being treated as stable progress.

## 为什么重要 / Why This Matters
中文：
这个基线让曲率语言具有受约束的参照点，同时保留理想对齐、可观察低偏差和真实成功之间的差异。

English:
The baseline gives curvature language a disciplined reference point while preserving the difference between ideal alignment, observed low deviation, and actual success.

## 这不是什么 / What This Is Not
中文：
这不是数学曲率模型，不是事实成功标签，不是执行成功保证，不是所有有效路径都必须笔直的主张，也不是 UX 或 prompt 写作技巧。

English:
This is not a mathematical curvature model, not a factual success label, not a guarantee of execution success, not a claim that every valid path is straight, and not a UX or prompt-writing heuristic.

## 开放问题 / Open Questions
中文：
如何在不发明公式的情况下描述残余偏差？什么证据足以称为低偏差？未来形式化是否可以引入更精确结构，同时不把当前候选文本改写成数学模型？

English:
How can residual deviation be described without formulas? What evidence is enough to call a deviation low? Can future formalization introduce more precise structure without rewriting this candidate as mathematics?

## 审查风险 / Review Risks
中文：
过度形式化曲率；把零曲率当成已经达成而不是理想基线；把 F 保真降维成任务完成；在 v0.3 审查前发明公式。

English:
Over-formalizing curvature; treating zero curvature as achieved rather than ideal; collapsing F preservation into task completion; inventing formulas before v0.3 review.
